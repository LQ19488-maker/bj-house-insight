## 6. 口径约定（**冻结，不得改动**）

| # | 项 | 约定 |
|---|---|---|
| 1 | 中位数 | 线性插值法（pandas 默认）。手册的 57992 / 81.33 是**上中位数**，本卡同时披露，不视为冲突 |
| 2 | KPI 均价 | **算术均值 64,764.78 元/㎡** |
| 3 | 对照均价 | **面积加权 64,028.12 元/㎡**（两者差 736.66，必须同时披露） |
| 4 | 极值判定 | 全市 P0.5–P99.5，三指标并集 **72 行**，**只标记不删除** |
| 5 | 区间分桶 | `left_open`，即 `(low, high]`；对非空原始值命中率 **100%** |
| 6 | 派生区间列 | 面积区间 / 总价区间 **不入库**，由前端按需分桶 |
| 7 | `house_tag` | **不建表**，房源标签并入 `house.near_subway` |
| 8 | one-hot | 36 列全部丢弃，回归原文字段（装修"其他"按 D2 整列丢弃） |
| 9 | 室 / 厅 | 入库；`厅=0` 合法 |
| 10 | 单价校验 | `单价 = 总价×10000/面积`，允许偏差 ≤ 1.00 元/㎡；实测超容差 **0 条** |

## 8. 粒度上限与混杂提示（做图前必读）

### 8.1 小区不是可统计粒度

| 指标 | 值 |
|---|---|
| 仅 1 套在售的小区 | **1257 / 1864（67.4%）** |
| ≤2 套在售的小区 | 1640（88.0%） |
| 在售套数中位数 / 最大 | 1 / 12 |
| 街道级样本中位数 | 7 |

→ 小区只作**检索标签**与"同小区相似房源"兜底；估价降级链：**同小区 → 同街道（n≈7）→ 同区**。

### 8.2 伪街道必须过滤

12 个名称 / 16 个组合 / **107 行**。街道排行与画像必须 `WHERE is_pseudo = 0`。

### 8.3 四个反直觉现象（不控制区位会得出错误结论）

| 现象 | 数值 | 真实原因 |
|---|---|---|
| 房龄与单价**正相关** | r = **+0.260**；30–50 年房龄均价 77,852 / 78,795 最高 | 老房集中在东西城核心区（辛普森悖论） |
| 塔楼比板楼**贵** | 塔楼 71,219 vs 板楼 61,136（**+16.6%**） | 板楼混入大量远郊大盘与城区老公房 |
| 面积与单价**几乎无关** | r = **−0.044**；面积与总价 r = **+0.719** | 面积主要解释总价，不解释单价 |
| 毛坯单价最低但中位总价最高 | 单价 55,946（最低）/ 中位总价 549.5 万（最高） | 毛坯多为大户型别墅 |

→ 所有"属性溢价"类图表**必须配同区控制对照**，否则结论站不住。
